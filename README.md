# ASD Detection

A system for detecting Autism Spectrum Disorder (ASD) in children using speech and facial cues.

## Tech Stack

- React (Frontend)
- FastAPI (Backend)
- Deep Learning (Speech & Facial Analysis)

## Installation

```bash
git clone https://github.com/MuhammedZohaib/FYP-2025.git
cd fyp-2025
npm install
npm run dev

cd ../app
pip install -r requirements.txt
uvicorn main:app --reload
```
